# 验证记录

## v0.3.16 历史版本数据浏览与清理

89 项 Swift 测试和 18 项 Python 测试在 arm64 下通过。新增历史版本数据的目录树与空间概览一致、混合文件夹清理时保留已并入聊天的附件并可恢复、未对应账号的旧版文件夹整体移入废纸篓、拒绝旧版账号文件夹以外的选择、文件变化后跳过、硬链接只计一次等检查；另覆盖旧版聊天附件并入新版会话、空间概览各模块合计、校验值缓存与索引快照清理。

29 项演示布局与交互检查通过，人工查看历史版本数据页、旧版账号文件夹和清理确认窗口截图。两个架构的 v0.3.16（build 24）应用、DMG、ZIP 已构建，签名、DMG 校验与随包 SQLCipher 启动检查通过；Intel（x86_64）安装包已通过发布前人工测试。

## 测试范围与限制

使用独立目录中的人工账号、数据库、图片、视频、普通文件及硬链接验证。没有读取用户真实聊天内容或密钥。原生测试在 Apple Silicon 上运行；macOS 14 / 15 和用户约 100GB 账号仍需实机验证。

安装包验证覆盖二进制架构、macOS 14 部署下限、应用签名及随包 SQLCipher 启动。当前采用 ad-hoc 签名，未做 Developer ID 签名或 Apple 公证。

本轮测试与打包日志、布局结果保存在本地 `build/validation/`。编译缓存、演示夹具和历史版本产物在验证后清理，可通过源码重新生成。
