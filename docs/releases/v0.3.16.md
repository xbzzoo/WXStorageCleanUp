# 微空间 v0.3.16

新增“历史版本数据”页面，可以按文件夹浏览旧版微信（3.x）留下的数据。只有旧版账号文件夹内的项目可以勾选；确认需要的旧聊天记录已能在新版中查看或已备份后，即可将选中项移入废纸篓，并可在“操作记录”中恢复。已并入新版聊天的旧版图片、视频等附件保留在原位。

本版本还包含以下改进：

- 旧版微信遗留的聊天图片、视频、语音和文件按聊天并入对应的新版会话，清理聊天附件时一起移入废纸篓。
- 空间概览统计微信的全部占用，包括数据容器、应用程序、扩展与共享容器，并按账号、内置浏览器与小程序、插件、日志、缓存等模块细分，各模块之和等于总占用。统一按磁盘实际占用计算，硬链接只计一次；“聊天与消息”“其他文件”的合计与概览中对应模块一致。
- “聊天与消息”分别显示各聊天独占的空间（清理后可释放）和与其他聊天或硬链接共享的空间，聊天按实际占用排序。
- 清理聊天完成后提示文字消息仍保留：如需删除文字，先在微空间中清理附件，再在微信中清空该聊天的聊天记录。清理“其他文件”和“历史版本数据”前需勾选确认。
- 扫描、附件索引和图片预览更快：扫描时预先识别附件类型，文件校验值跨启动缓存，图片预览改为并发解码。
- 每个已连接账号只保留当前使用的一份只读索引快照，重新连接、连接失败或忘记连接后会自动删除多余快照。

安装：选择 Intel（x86_64）或 Apple Silicon（arm64）的 DMG，打开后将“微空间.app”拖入应用程序。升级前退出旧应用，再替换。账号连接和操作记录保留。自动连接需要 Xcode 或 Command Line Tools，并由本人完成临时微信登录授权。

最低 macOS 14.0。应用采用 ad-hoc 签名，尚未 Apple 公证。清理仅移入废纸篓，清空相应项目后才可能释放空间。更完整的操作说明见仓库 README。

验证：89 项 Swift 测试和 18 项 Python 测试在 arm64 下通过，29 项演示布局与交互检查通过；Intel（x86_64）安装包已通过发布前人工测试。macOS 14 / 15 及用户真实大账号尚未完整实机回归。
