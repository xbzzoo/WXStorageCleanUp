# v0.3.3 本地修复版

此版本已生成本地安装包，尚未发布到 GitHub Release。

## 自动连接

- 为临时微信副本保留原容器主目录，修正移除沙盒签名后可能转到另一数据目录、登录成功却一直匹配不到所选账号密钥的问题。真实微信行为仍需在原问题设备复测。
- 在连接窗口持续显示已验证数量、已等待时间、剩余时间和仍缺少的数据库。
- 显示超时、临时微信提前退出、崩溃、调试启动被拒绝等原因，已验证的部分密钥保留以便重试。
- 在连接面板直接显示错误，增加所选账号密钥的 Finder 定位入口，以及随包的 [连接排查与本地密钥操作指引](../connection-guide.md)。
- 更正界面中的架构说明：自动取钥支持 Apple Silicon 和 Intel，仍需 Xcode 或 Command Line Tools。

## 附件列表

- “未归属附件”统一更名为“未匹配聊天的附件”，说明已扫描到文件但尚未匹配到具体聊天。
- 移除每行的“在 Finder 中查看”文字按钮，点击附件行直接在 Finder 中定位文件。
- 复选框独立控制清理选择。

## 验证

38 项 Swift 测试分别在 arm64 和 Rosetta x86_64 下通过，9 项 Python 测试通过，arm64 安装应用通过 19 项演示界面检查。实际取钥验证仅使用人工 Foundation / CommonCrypto 程序；真实微信和原问题设备的复测尚待完成。详见 [验证记录](../validation.md)。
