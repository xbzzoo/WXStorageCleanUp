# 微空间 v0.3.14

移除主界面右上角重复的“微空间”文字，将“预览清理”按钮改为“清理”，左下角显示应用自身的版本号。清理仍先列出待处理项目供确认，再移入废纸篓。

本版本还包含以下改进：

- 主界面顶部账号旁提供绿色“连接聊天”按钮。扫描完成后，未连接账号自动打开连接面板；有效保存索引恢复成功时不重复提示。
- 连接面板只保留自动获取密钥并连接；修复输出管道和数据库解锁可能无限等待的问题，补充数据库、处理阶段、输出大小和等待时间。
- 根据已扫描的聊天图片文件建立资源映射，支持原图、高清与缩略图变体，并补充消息正文中的图片标识，减少本地图片存在但未匹配的情况。
- 聊天统计与筛选在后台处理，消息和“其他文件”列表分页加载，加载更多位于列表底部。聊天清理直接将专属附件文件夹移入废纸篓并更新列表。
- 图片支持本地预览和 Finder 定位；扫描和连接期间锁定应用操作，完成或失败后恢复。

安装：选择 Intel（x86_64）或 Apple Silicon（arm64）的 DMG，打开后将“微空间.app”拖入应用程序。升级前退出旧应用，再替换。自动连接需要 Xcode 或 Command Line Tools，并由本人完成临时微信登录授权。

最低 macOS 14.0。应用采用 ad-hoc 签名，尚未 Apple 公证。清理仅移入废纸篓，清空相应项目后才可能释放空间。更完整的操作说明见仓库 README。

验证：连接和图片等功能的 65 项 Swift 测试在 arm64 与 Rosetta x86_64 下通过；本次界面文字与版本显示调整完成 24 项演示布局和交互检查。Intel 真机、macOS 14 / 15 及用户真实大账号尚未实机回归。
