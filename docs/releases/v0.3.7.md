# v0.3.7 聊天清理统一口径

聊天显示的附件逻辑大小、附件数量和“清理此聊天”的预览均使用 ConversationUsage.filePaths。该清单包含聊天目录中发现的文件，以及消息索引定位的分散附件；不再要求文件先匹配到具体消息。消息列表仅用于浏览和定位，类型、日期、关键词筛选不改变整聊清理范围。

移除聊天列表复选框、批量勾选、消息复选框和共享引用开关。点击一个聊天后，直接预览该聊天全部附件，再用确认按钮执行。未匹配聊天附件模块仍保留逐文件选择。

清理包含硬链接路径，也允许移除被其他消息引用的当前路径。不会自动追加聊天统计范围以外的其他硬链接路径；因此显示占用与预览清单保持一致。共享当前路径的其他消息可能受影响，预览中有说明。文字消息和数据库保留，附件仍移入废纸篓。

“在 Finder 中打开聊天附件文件夹”优先打开账号 msg/attach/<聊天哈希>。文件或视频可能分散存储在其他目录；该目录不存在时打开账号 msg。完整附件路径见预览，不能将一个目录视为全部附件的物理位置。

扫描不完整、路径越界、账号不符、外部未绑定索引或文件已变化时仍中止操作。文件变化时要求重新扫描，不再默默过滤为零文件，从而避免统计与预览不一致。

新增无消息映射时的目录清理检查：预览路径集合、逻辑大小均与聊天统计严格一致，且拒绝跨账号调用。安装包本地生成，尚未发布到 GitHub。
