# v0.3.8 全局加载状态

扫描本地微信、连接账号以及后续索引整理期间，主窗口与连接面板显示覆盖整个内容区域的 loading，持续展示当前步骤，完成或失败后自动恢复操作。

加载期间禁用侧栏、列表、按钮、搜索、导出及数据目录选择快捷键；连接面板禁止交互式关闭，窗口关闭、最小化、缩放与应用退出入口禁用。加载层没有取消按钮。独立微信窗口及系统授权提示仍可正常操作，以完成登录授权。

操作入口同时检查 busy 状态，避免菜单或其他入口绕过加载层。此状态也覆盖后台清理预览和文件操作，避免任务进行时改动选择。

人工检查覆盖主窗口加载遮罩、连接面板遮罩、加载期间点击侧栏无效、加载结束后侧栏与窗口关闭按钮恢复。安装包仅本地生成，尚未发布到 GitHub。
