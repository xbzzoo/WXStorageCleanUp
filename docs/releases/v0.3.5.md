# v0.3.5 本地修复版

修复旧版 Command Line Tools 下，临时微信启动后报“无法继续运行”并中止连接的问题。此前 v0.3.3 / v0.3.4 处理目录与退出问题，未覆盖此调试器兼容问题。

- 兼容旧 LLDB 的 `process still running` 与新版本的 `process already running`。运行中的进程不再被误判为恢复失败。
- 按真实进程状态事件处理暂停，忽略已自动恢复的启动事件及其他进程事件，同一暂停只处理一次。
- 兼容旧 LLDB 的无参数 `Detach()` 接口，并等待暂停状态后解除调试。
- 区分权限拒绝、恢复失败、进程退出、崩溃和观察点未解析；不再把恢复失败统一提示成权限问题。
- 增加「复制连接诊断」，按账号保存在本机私有文件中。只记录版本、数量和结构化调试状态，不记录密钥、聊天内容、绝对路径或原始调试错误文本。

独立的 Command Line Tools 可满足开发工具需求，无需完整 Xcode。检查命令及手动密钥导入方法见 [连接操作指引](../connection-guide.md)。

测试覆盖现行 LLDB 的 arm64 / Rosetta x86_64，以及 Command Line Tools 14.3.1 / LLDB 1403 的 Intel 人工多线程取钥流程。旧工具链测试为兼容性夹具，使用本地同 ABI 入口再调用 CommonCrypto，以避开其无法解析 macOS 26 共享缓存的问题。仍未在用户的 Intel、macOS 15.8.1、微信 4.1.15 环境完成真实登录回归，不能将人工测试等同于该环境连接成功。

18 项 Python 测试通过，45 项 Swift 测试分别在 arm64 和 Rosetta x86_64 下通过。详见 [验证记录](../validation.md)。

安装包仅在本地生成，尚未发布到 GitHub Release。
