# WXStorageCleanUp v0.3.2 · 预览版

工程及应用统一更名为 **WXStorageCleanUp**（原「微空间」），增加 **Intel / x86_64 安装包**，修复 Intel Mac 无法打开 arm64 应用的问题。自动连接组件增加 x86_64 参数解析，已通过人工程序的真实 LLDB 取钥验证；未使用真实聊天内容做该项测试。

## 下载与安装

- **最低部署版本：macOS 14.0。请按「关于本机」显示的芯片 / 处理器选择。**
- **Intel Mac（包括 macOS 15.8.1）：下载 `WXStorageCleanUp-0.3.2-macOS-x86_64.dmg`。**
- Apple Silicon（M 系列）：下载 `WXStorageCleanUp-0.3.2-macOS-arm64.dmg`。
- 打开 DMG 后将「WXStorageCleanUp.app」拖入 Applications，再从「应用程序」启动。
- 也可下载 ZIP，解压并复制应用到「应用程序」。
- 使用同页 `SHA256SUMS.txt` 校验下载完整性；对应架构的 `.compatibility.json` 列出各组件部署版本和架构。
- 升级前退出旧版；从「微空间」升级时，请在安装新应用后删除旧「微空间.app」。账号连接、快照和操作记录继续沿用原私有目录。

**本预览版尚未获得 Developer ID 签名与 Apple 公证。** Gatekeeper 可能阻止首次打开；核对来源后，可按 [Apple 官方说明](https://support.apple.com/102445)对该应用单独放行。不要关闭 SIP 或全局安全检查。

扫描和手动附件整理不需要 Homebrew；SQLCipher、OpenSSL、Zstandard 已随包提供。首次自动获取索引密钥仍需要 Xcode 或 Command Line Tools 的系统 Python / LLDB，以及本人完成登录确认。

## 本次包含

- arm64 与 x86_64 分别构建全部依赖，打包时逐组件验证架构和 macOS 14.0 部署目标。
- README 增加芯片与下载包对照表、架构不匹配说明及改名升级步骤。
- 原创“聊天气泡 × 收纳抽屉”应用图标，完整 Finder / Dock 图标尺寸。
- 微信空间概览、聊天 / 消息级附件整理和多账号切换。
- 未归属附件按类型、文件名和路径搜索，允许手动选择共享硬链接路径。
- 固定侧栏、浅色聊天选中背景、突出本机扫描入口。
- 清理完成后的废纸篓强提示、Finder 定位、逐项操作记录及恢复。

## 数据与空间说明

清理只移入废纸篓，保留微信数据库及文字消息。核对并清空相应废纸篓项目后才可能回收空间；其他硬链接、APFS 克隆或快照可能继续保留数据。

未归属附件可能仍被聊天使用，媒体索引适配尚未完整覆盖。恢复依赖废纸篓项目仍存在，并且原位置没有新文件；清空后无法通过本工具恢复。自动连接时临时微信会正常联网并可能更新缓存，请提前保存草稿。

源码、安装包不包含个人账号密钥、聊天数据库、扫描报告或操作日志。此版本的实机验证范围为 Apple Silicon、macOS 26；x86_64 在 Rosetta 下验证，Intel 真机及对应微信构建尚未验证。

macOS 14 / 15 及 Intel 真机尚未实机回归；最低部署版本和架构已逐组件核对。旧安装包已撤换，请使用本版匹配芯片的安装包。
