# 自动连接聊天索引

连接面板仅提供“自动获取密钥并连接”。选择本机账号后点击“自动连接所选账号”；已有有效密钥时自动复用，首次连接会退出微信并打开临时窗口。

## 连接步骤

1. 扫描本机微信。扫描完成后，未连接的账号会自动打开连接面板；也可点击主界面顶部账号旁的“连接聊天”（已连接时为“管理连接”），选择需要整理的账号。
2. 保存微信草稿后点击“自动连接所选账号”。
3. 在临时微信中进入同一账号，并完成手机确认。
4. 打开联系人、含图片的聊天及较早的历史消息，让微信加载所需数据库。
5. 等待验证完成。工具会关闭临时微信、建立索引并自动返回聊天列表。

连接及索引整理期间，工具窗口显示全局 loading，完成或失败后恢复操作。独立微信窗口及系统授权提示可正常操作。临时微信使用本机账号数据，可能更新登录状态及缓存，建议仅用于登录和加载聊天。

## 没有继续连接时

连接面板会显示验证数量和具体失败原因。本轮等待上限约 4 分钟，已验证的有效密钥会保留，重试时自动复用。确认所选账号与临时微信登录账号一致；查看等待中的数据库，并打开对应的联系人、图片或更早的历史消息。

若提示临时微信仍在运行，先对临时窗口按 ⌘Q；无窗口时在活动监视器中核对错误提示里的 KeyCapture 临时路径后正常退出对应进程，再重试。

自动连接支持 Apple Silicon / Intel，需要 Xcode 或独立 Command Line Tools。可在终端用 `xcode-select -p` 和 `xcrun lldb --version` 检查工具安装；未安装时执行 `xcode-select --install`。已有工具时通过系统软件更新检查适配当前 macOS 的版本。[Apple 安装与更新说明](https://developer.apple.com/documentation/xcode/installing-the-command-line-tools)

## 停在读取本地索引的最后一步

连接过程分别显示复制、解锁、校验和消息解析阶段；解锁时显示数据库名和已生成数据大小。数据大小持续增长说明仍在处理；默认连续 5 分钟没有增长或总时长超过 1 小时会停止解锁并返回错误。若仍长时间等待，请记录完整阶段文字、等待秒数和已生成的数据大小，不需要提供数据库或密钥。
